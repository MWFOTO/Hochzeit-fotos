# Kundenweg

Landingpage / → Registrierung /register (E-Mail und Passwortbestätigung) → geschütztes Dashboard → Veranstaltung erstellen → Stripe-Testzahlung → QR-Code/Galerie. Bestehende Kunden melden sich unter /login an. Gäste benötigen weiterhin kein Konto.

Keine Werbeversandfunktion und keine automatische Werbeeinwilligung eingerichtet. Eine spätere Newsletter-Anmeldung muss unabhängig vom notwendigen Veranstalterkonto gestaltet werden.
